# STM32 四轮麦轮全向遥控小车

基于 **STM32F103C8T6** 的四轮麦克纳姆轮（Mecanum）全向移动小车运动控制固件。
通过 2.4G 遥控器（Microzone MC6C）操控，支持前进/后退、横向平移、原地自旋，以及一路舵机角度输出。

固件用 C 语言编写，基于 **STM32Cube HAL**，在 **Keil MDK-ARM (ARMCC V5)** 下开发。

---

## 功能

| 功能 | 说明 |
|---|---|
| 全向移动 | 前进 / 后退 / 左右平移 / 斜向移动 |
| 原地自旋 | 四轮配合绕中心旋转 |
| 舵机输出 | 50 Hz PWM，左右各约 80° 行程 |
| 遥控解码 | 4 通道输入捕获，1000–2000 µs |
| 失效保护 | 连续 150 ms 收不到信号 → 全部停车 |
| 起步助力 | 起步瞬间 1.5 倍占空比冲 150 ms，解决低速不启动 |
| 直行补偿 | 抑制麦轮跑偏（随速度衰减） |

## 硬件

| 部件 | 型号 / 规格 |
|---|---|
| 主控 | STM32F103C8T6，Cortex-M3，72 MHz，128 KB Flash |
| 底盘 | 四轮麦克纳姆轮底盘 |
| 电机 | 4 × 直流减速电机，带编码器盘（当前未接入） |
| 驱动 | L298N × 2（每片 2 路） |
| 遥控 | Microzone MC6C，2.4G，4 通道，PWM 输出 |
| 舵机 | 标准 50 Hz 模拟舵机 |
| 电源 | 电池 → 降压模块 → 5 V 供接收机与舵机 |

> ⚠️ 舵机与接收机的额定电压是 4.8–6 V，**不要直接接 8 V**，会过热并导致中位抖动。

## 引脚分配

### 电机（TIM2，5 kHz 中心对齐 PWM，部分重映射 2）

| 轮位 | PWM | 正转 | 反转 |
|---|---|---|---|
| 左前 LF | PA0 (CH1) | PA3 | PA5 |
| 右前 RF | PA1 (CH2) | PB1 | PB0 |
| 右后 RR | PB10 (CH3) | PB13 | PB12 |
| 左后 LR | PB11 (CH4) | PA10 | PA11 |

**L298N 的 ENA / ENB 跳线帽必须拔掉**，否则 PWM 调速无效。

### 遥控接收机（输入捕获）

| 通道 | 引脚 | 功能（左手模式，MC6C 出厂默认） |
|---|---|---|
| CH1 | PA8 (TIM1_CH1) | 右摇杆 左右 → 原地自旋 |
| CH2 | PA9 (TIM1_CH2) | 右摇杆 上下 → 舵机 |
| CH3 | PB8 (TIM4_CH3) | 左摇杆 上下 → 前进/后退 |
| CH4 | PB9 (TIM4_CH4) | 左摇杆 左右 → 横向平移 |

切换左右手模式：修改 `main.c` 中的 `RC_HAND_MODE`（2 = 左手，1 = 右手）。

### 舵机

PA6 (TIM3_CH1)，50 Hz，1 µs 分辨率。

## 软件结构

```
RC 接收机 ──输入捕获──> rc_pulse[1..4]
                            │
                     死区 / 非线性曲线
                            │
                     麦轮逆运动学混控
                            │
                    归一化限幅 + 起步助力
                            │
                    TIM2 四路 PWM ──> L298N ──> 电机
```

### 麦轮逆运动学

```
vx = 前进(+)/后退(−)     vy = 右移(+)/左移(−)     wz = 自旋
lf = vx + vy + wz        rf = vx - vy - wz
lr = vx + vy - wz        rr = vx - vy + wz
```

### 主要参数

| 宏 | 值 | 作用 |
|---|---|---|
| `RC_DEADBAND` | 25 µs | 摇杆中位死区 |
| `STICK_MIN_MOVE` | 50 | 摇杆离开中位即输出 50%，线性升到 100% |
| `MOT_KICK_MS` / `MOT_KICK_NUM/DEN` | 150 ms / 3/2 | 起步 1.5 倍冲击 |
| `MEC_KICK` | 14 | 低速时右轮补偿量（%），随速度衰减到 0 |
| `MEC_STRAFE_TRIM` | 8 | 平移时抑制前向分量 |
| `SERVO_US_ZERO` | 1400 µs | 舵机正前方 |
| `SERVO_US_MIN/MAX` | 572 / 2223 µs | 左 80.5° / 右 80° |
| `SERVO_CENTRE_DEAD` | 100 µs | 舵机中位死区 |

## 开发中解决过的问题

**1. 舵机中位抖动**
两个独立原因叠加：

- 更新比较值时若正好落在脉冲高电平期间，会截断当前波形 → 打开 **CCR 预装载**（`OCxPE` + `EGR`），新脉宽在下一帧才生效。
- 摇杆中位存在 1–2 µs 噪声，反复跨越死区边界 → 加 100 µs 中心死区，并把映射改为**压缩行程**而非留空档：摇杆离开死区时输出正好从中位开始，不产生跳变，同时满舵行程毫无损失。

**2. 麦轮直线跑偏**
前进左偏、后退右偏且前后不对称。通过观察四轮起转顺序（左前→右后→左后→右前）定位到右前轮偏弱，用**随速度衰减的补偿量**修正——低速补得多，满速不补。

**3. 低速轮子不启动**
同一占空比下四个电机的启动电压不同，改用「起步 1.5 倍冲击 150 ms，之后回落到最低 50% 的线性曲线」。

## 已知限制

- **开环控制**：没有轮速反馈，补偿量是经验标定值，电池电压或负载变化后需重新调整
- 四个电机个体差异较大，同一占空比转速并不一致
- 舵机与接收机当前由 8 V 直接供电，超出规格，长期可能损坏
